Magnetoti - תוכנה ליצירת דפי מגנטים להדפסה (Windows 10/11)

דרישות: Python 3.10 ומעלה (מ-python.org, לסמן Add Python to PATH בהתקנה)

הפעלה מהירה:   לחיצה כפולה על run.bat
יצירת EXE:     לחיצה כפולה על build_exe.bat  ->  dist\Magnetoti.exe

קובץ התקנה:    build_installer.bat  ->  installer_output\Magnetoti_Setup.exe

בנייה בענן ללא Python: להעלות את התיקייה ל-GitHub, לשונית Actions -> Build Windows Installer -> Run workflow -> להוריד Magnetoti_Setup
